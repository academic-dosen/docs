### Mengelola Profil Pribadi

<Note>
  Profil Dosen berisi data pribadi pengguna portal akademik. Apabila terdapat kesalahan data, anda dapat menghubungi bagian akademik untuk memperbaikinya.
</Note>

1. **Login pada Portal Akademik menggunakan akun Anda**

   Masukkan username dan password pada halaman login, kemudian tekan tombol **Login** untuk mengakses fitur-fitur di Portal Akademik.
2. **Tekan menu Profil**

   Sistem akan menampilkan data pribadi dosen. Pada menu ini Anda tidak memiliki akses untuk mengubah data Anda, Anda dapat memperbaiki data dengan mengubungi bagian akademik.
