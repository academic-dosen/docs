---
title: "File Sharing"
---

**File Sharing** merupakan fitur pada menu **Virtual Class** yang digunakan oleh dosen untuk mengunggah dan membagikan berbagai file pendukung pembelajaran kepada mahasiswa. File yang dibagikan dapat berupa materi perkuliahan, modul, referensi, atau dokumen lainnya yang berkaitan dengan kegiatan pembelajaran.

### Cara Mengakses Menu File Sharing

1. Login pada Portal Akademik menggunakan akun Anda

   Masukkan username dan password pada halaman login, kemudian tekan tombol **Login** untuk mengakses fitur-fitur di Portal Akademik.
1. Tekan menu **Virtual Class** \> **File Sharing**\
   Akan menampilkan data **File Sharing** yang dishare oleh pengguna portal akademik. Anda juga dapat melakukan pencarian data dengan menggunakan fitur **search.**

   <Frame>
     ![File Sharing D Daftar](/images/FileSharingD.Daftar.png)
   </Frame>
1. Tekan tombol **Tambah File Sharing**

   Form tambah file sharing bisa Anda lengkapi, Anda juga dapat melakukan unggah file yang ingin dishare.

   <Frame>
     ![File Sharing D Tambah File](/images/FileSharingD.TambahFile.png)
   </Frame>
   <Frame>
     ![File Sharing D Input Form](/images/FileSharingD.InputForm.png)
   </Frame>
1. Tekan tombol **Simpan**\
   Anda dapat melakukan klik tombol Simpan untuk menyimpan dan membagikan file kepada mahasiswa.

   <Frame>
     ![File Sharing D Simpan Form](/images/FileSharingD.SimpanForm.png)
   </Frame>
